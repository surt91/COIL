- Append to `notes/devlog.md`, **in German**, heading `## YYYY-MM-DD — <Titel>`.
- Write for a technically curious reader of a blog: what problem, what
  surprised us, what we decided and *why*, what it cost. Keep it concise.
- Include concrete evidence: numbers before/after (bot win rates, crush share),
  short quotes from agent reports or the commissioner, tiny code or ASCII
  snippets when they tell the story better than prose.
- Credit the process: which agent role found what (playtester, art-critic,
  code-guardian, …), and dead ends worth telling.
- Don't duplicate git history — pick the interesting parts.
